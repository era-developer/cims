# KIMS Student Quick Cheat Sheet

**Kalam Pragati Inventory Management System.** Use this as a fast reference during onboarding and demo sessions.

## 1) First time setup

1. Open the KIMS URL given by your center.
2. Click `Student Register`.
3. Fill required fields and submit.
4. Wait for admin approval.
5. Sign in with your username/email and password.

## 2) Main pages

- `Browse`: search and select components.
- `Cart`: review selected items and submit request.
- `My Orders`: track status and raise return request.
- `My Profile`: keep contact and academic info updated.

## 3) Place a request

1. Add components from `Browse`.
2. Open `Cart`.
3. Fill required project details:
   - student name
   - email/mobile
   - college/department
   - project/course
   - expected return date
   - purpose
4. Accept the terms and submit.
5. Enter the one-time code emailed to you to confirm.

## 4) Status meaning

- `Pending`: waiting for admin review.
- `Approved`: request issued.
- `Rejected`: not approved.
- `Return Requested`: waiting for admin return verification.
- `Partially Returned`: some quantity still pending.
- `Returned`: fully closed.

## 5) Return process

1. Open approved order in `My Orders`.
2. Click `Request Return`.
3. Hand components to admin.
4. Admin verifies returned/damaged quantity.

## 6) Student do/don't

Do:
- Request only what is needed.
- Return on time.
- Report damaged parts honestly.

Don't:
- Keep pending balance for long.
- Share account credentials.
- Borrow/return outside portal flow.

## 7) Quick troubleshooting

- "Awaiting admin approval": ask center admin to approve user.
- "Insufficient stock": reduce quantity or try later.
- Cannot submit request: check required fields and return date.
