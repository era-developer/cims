# CIMS Simple Guide (English + Kannada in Roman script)

This is a simplified training guide for center-level orientation.

## 1) Student registration and login

- EN: Click `Student Register`, fill form, submit, wait for admin approval.
- KN: `Student Register` mele click madi, form fill madi, submit madi, admin approval ge wait madi.

- EN: After approval, login with username/email and password.
- KN: Approval aadmele username/email mattu password inda login madi.

## 2) Student order flow

- EN: Go to `Browse`, search component, add to cart.
- KN: `Browse` ge hogi, component huduki, cart ge add madi.

- EN: Open `Cart`, fill project details, submit request.
- KN: `Cart` open madi, project details fill madi, request submit madi.

- EN: Track status in `My Orders`.
- KN: Status na `My Orders` alli nodi.

Status quick meaning:
- EN: Pending = waiting admin
- KN: Pending = admin nodbeku
- EN: Approved = issued
- KN: Approved = issue agide
- EN: Returned = closed
- KN: Returned = close agide

## 3) Admin daily flow

- EN: Approve student registrations in `Users`.
- KN: `Users` alli student registration approve madi.

- EN: Review pending orders in `Orders`.
- KN: `Orders` alli pending requests check madi.

- EN: While approving, you can reduce qty or remove item.
- KN: Approve madovaga qty kammi madbahudu athava item remove madbahudu.

- EN: Process return requests and update returned/damaged qty.
- KN: Return request process madi, returned/damaged qty update madi.

## 4) Center-to-center transfer flow

- EN: Center admin raises request in `My Center`.
- KN: Center admin `My Center` alli request raise madtare.

- EN: Super admin approves in `Transfers` and assigns supply center.
- KN: Super admin `Transfers` alli approve madi supply center assign madtare.

- EN: Requesting center raises return request after usage.
- KN: Usage mugida mele requesting center return request raise madtare.

- EN: Super admin marks transfer returned.
- KN: Super admin transfer na returned anta mark madtare.

## 5) Report download

- EN: Dashboard has download buttons for inventory, orders, transfers, users, and logs.
- KN: Dashboard alli inventory, orders, transfers, users, logs report download options ide.

## 6) Common issues quick fix

- EN: "Awaiting approval" -> admin should approve in `Users`.
- KN: "Awaiting approval" andre admin `Users` alli approve madbeku.

- EN: "Insufficient stock" -> reduce qty or select another center (transfer flow).
- KN: "Insufficient stock" andre qty kammi madi athava bere center select madi.

- EN: Request not visible -> check status tab and center filter.
- KN: Request kanasilla andre status tab mattu center filter check madi.
